# Бизнес-аналитик Keme AI

Автономный агент для анализа операционных показателей. Требуется Python 3.10 или новее. Подключение к интернету, установка пакетов и ключи API для запуска не нужны.

## Запуск

Выполните команды из корня репозитория.

```powershell
python -m agents.business_analytics --example
python -m agents.business_analytics "Как понять, почему падает средний чек?"
python -m agents.business_analytics "Почему упал средний чек и где покупатели уходят до оплаты?"
python -m agents.business_analytics "Сравни выручку и маржу" --csv "продажи.csv"
python -m agents.business_analytics "Как проверить A/B-тест и где покупатели уходят до оплаты?"
python -m agents.business_analytics "Сравни 2026-01 и 2026-03" --example
python -m agents.business_analytics "Выручка по регионам с января по март" --example
python -m agents.business_analytics "Сводка с 2026-01 по 2026-03" --csv "продажи.csv" --group-by channel --json
```

Ключ `--lang ru|kk|en` задаёт язык ответа. По умолчанию агент определяет язык по вопросу. Ключ `--json` добавляет машиночитаемые поля `intent` для основной темы и `topics` для всех распознанных тем. Поле `data` содержит итоговые значения, данные по месяцам, сравнение и сведения о пропусках. Десятичные значения передаются строками с точкой.

## Какие задачи распознаёт агент

- Прибыль и маржа
- Продажи, объём заказов и средний чек
- Конверсия и воронка
- Рекламная эффективность и ROAS
- Качество данных
- Отчёты для руководителя и выбор KPI
- Сравнение периодов
- Удержание, отток и когортный анализ
- Запасы, оборачиваемость и дни покрытия
- План-факт и бюджетные отклонения
- Дизайн и оценка A/B-тестов
- Юнит-экономика, CAC и точка безубыточности
- Сроки доставки, отмены и возвраты

Локальная модель обучается на 768 размеченных формулировках из [training.json](training.json). Она сопоставляет запрос с примерами и учитывает бизнес-термины. Если в запросе несколько задач, агент даёт методику и список нужных данных для каждой. При низкой уверенности агент уточняет задачу. Числа из таблицы рассчитываются кодом с десятичной арифметикой для показателей из раздела «Формат таблицы». Для когорт, запасов, план-факта, экспериментов, юнит-экономики и доставки агент объясняет методику и перечисляет поля, которые нужно собрать.

## Формат таблицы

За основу можно взять [example.csv](example.csv). Агент принимает один CSV или TSV в UTF-8 размером до 128 КиБ, до 5000 строк и 64 колонок. Поддерживаются запятая, точка с запятой или табуляция между полями. Если десятичная запятая совпадает с разделителем полей, заключите число в кавычки или при экспорте выберите точку с запятой.

| Колонка | Что указывать |
| --- | --- |
| `period` | Дату `YYYY-MM-DD` или месяц `YYYY-MM`. Выберите один формат на весь файл. |
| `revenue`, `cost` | Выручку и учтённые затраты в одних единицах. |
| `orders` | Число заказов за период, представленный строкой. |
| `visits`, `conversions` | Визиты и число целевых действий в одной выборке. |
| `ad_spend`, `ad_revenue` | Расходы на рекламу и выручку, отнесённую к ней за сопоставимое окно атрибуции. |
| `currency` | Один код валюты, например `KZT`. Если валюта указана, заполните её во всех строках. |
| `region`, `channel`, `product`, `category`, `sku` | Необязательные колонки для разбивки по региону, каналу, товару, категории или артикулу. |

Достаточно одной колонки с числовым показателем. Для расчёта производного KPI нужны все его исходные колонки. Суммы рассчитываются по заполненным ячейкам, а отчёт отмечает неполное покрытие. Доли и сравнения требуют полных данных для используемых показателей. При повторяющихся строках агент предупреждает о дублях и включает строки в итог, поскольку одинаковые значения могут относиться к разным операциям.

По умолчанию агент сравнивает два последних соседних месяца. Укажите один месяц для отдельной сводки, два через «и» для сравнения или диапазон, например «с 2026-01 по 2026-03». На английском подходят формулировки `Compare Jan to Mar` для сравнения и `Revenue from Jan to Mar` для диапазона. Диапазон включает оба конца и все месяцы между ними. В отчёте видны пропущенные месяцы и неполные месяцы дневной выгрузки. Итоги по диапазону считаются по имеющимся строкам. Название месяца без года подходит, когда такой месяц встречается в файле один раз. В JSON поле `scope` содержит выбранные месяцы, число строк исходного файла и сведения о диапазоне.

Для сравнения по дневной выгрузке нужна запись на каждый календарный день выбранного месяца, в том числе на дни с нулём. Для месячной выгрузки каждая строка должна относиться к полному месяцу. Складывайте в одном файле только непересекающиеся срезы, чтобы одни и те же операции учитывались один раз. При нулевой или отрицательной базе агент показывает изменение в единицах показателя в поле `comparison.absolute_changes`. Для долей по-прежнему используются процентные пункты.

Чтобы выбрать разбивку, напишите «по регионам», «по каналам», «по товарам», «по категориям товаров» или «по артикулам» либо укажите одну колонку через `--group-by`. Пустые ячейки группируются под меткой «Без значения». Коды вроде `NA` сохраняются как названия групп. Средний чек и другие доли рассчитываются по суммам внутри каждой группы. При явном сравнении двух месяцев агент показывает изменение в каждой группе, где есть полные данные за оба месяца. Полный список групп доступен в `data.breakdown` с `--json`. Заголовки вне расчёта отмечаются предупреждением.

## Проверка

```powershell
python -m unittest agents.business_analytics.test_agent -v
```

Проверки покрывают контрольный расчёт, нулевые знаменатели, дубли, пропуски, диапазоны, разбивку по группам и разные форматы CSV. Для оценки распознавания используются [48 исходных](test_cases.json), [62 сложных вопроса](challenge_cases.json) и [56 сценариев по новым темам](advanced_cases.json). Сложный вопрос считается решённым, если набор распознанных тем полностью совпадает с ожидаемым. Эти наборы использовались для проверки и настройки модели.
