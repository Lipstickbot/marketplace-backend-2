# Тестовая оплата Keme AI

В бизнес-кабинете откройте **Тестовая оплата**. Доступны сценарии успешного платежа и отказа. Тестовая сумма составляет 1 000 ₸. Сценарий проверяет интерфейс и результат разового платежа.

## Песочница PayLink

1. Получите у PayLink ID магазина и ключ для тестовых операций.
2. Добавьте на сервер переменные окружения `PAYLINK_TEST_SHOP_ID` и `PAYLINK_TEST_SECRET_KEY`. Для локального запуска их можно записать в игнорируемый Git файл `.env`.
3. Перезапустите Backend 2. На официальном сайте или разрешённом локальном адресе войдите как бизнес и нажмите **Начать тест**.
4. На странице PayLink используйте [тестовые данные](https://docs.paylink.kz/ru/using_api/testing/). После возврата в кабинет сервер сверит статус и параметры операции с PayLink.

Форма PayLink размещена у провайдера. Backend 2 всегда отправляет `test: true`. Тестовый статус не открывает доступ к агентам и не создаёт выручку или выплаты. При отсутствии ключей кабинет показывает симуляцию.

Реальный приём денег и выплаты авторам требуют отдельного договора с провайдером и согласования схемы работы маркетплейса. Для распределения средств у PayLink есть [разделение платежа](https://docs.paylink.kz/ru/payment_management/split-2/).
